# flu-harness-landing — agent notes

Landing page for flu-harness. Next.js App Router, single page.

## Read before writing Next.js code

This Next.js version has breaking changes: APIs, conventions and file structure
may differ from what you expect. Before writing or changing anything in `app/`,
read the relevant guide under `node_modules/next/dist/docs/` and heed deprecation
notices. The `LayoutProps<"/">` type in `app/layout.tsx`, for example, is
generated by this version.

## Where things live

- `app/content.ts` — every visible string, in EN / PT / ES. Typed, so a missing
  translation is a compile error. Change copy here, not in `page.tsx`.
- `app/page.tsx` — layout and structure only. Text comes from `content.ts`.
- `app/globals.css` — design tokens and component classes.
- `app/layout.tsx` — fonts via `next/font`, metadata, `<html lang>`.

## Rules that are checked, not preferences

- **No em dashes** in user-visible copy. Use a colon, comma, or hyphen.
- **One accent colour, one corner radius (zero), one theme (light).** Do not
  introduce a second of any of them.
- **Two CTAs must not share an intent with different labels.** "View on GitHub"
  is used everywhere that link appears.
- **Hero holds four text elements at most**, and its subtext is capped at 20
  words.
- **Section eyebrows are capped at `ceil(sectionCount / 3)`.** With eight
  sections, three carry one.
- **No fabricated screenshots.** The terminal panel and the detection grid are
  the visuals; a div-based fake UI would be worse than either.
- Keep `.blueprint` frames paired with `<Corners />`. The class without the ticks
  looks like a missing asset.
